# Censored-path v1：不完整观测下的整段未来占据

2026-09-26。用户授权：根据当前分析实现新版，并提交 H200，在相同训练预算下与 A 对照。本文记录预先固定的实现与评估约定；启动或审计通过不代表预测收益。

## 问题与设计

任务仍为相机—雷达的 1/2/3 秒三维语义占据预测。检验的假设是：在部分可见监督下，把三个未来输出约束为同一场景假设，并保持真实实例的跨时刻匹配，比继续细化速度融合更值得尝试。没有假定速度无效，也没有声称当前误差已被证明主要来自遮挡。

1. **从逐时刻输出改为整段假设。** 保留 A 的相机骨干、时域 decoder 和 radar transport，只执行一次大模型前向。新的共享路径头从四个时域的历史传感器查询特征预测 K=2 个场景假设；同一查询在所有未来时刻共用两个三维系数。当前时刻直接旁路，未来残差为 `6*u*tanh(a+u*b)` 米，`u=t/3秒`，逐坐标有界。原 A 的独立未来形状仍在，因此这是共享时间残差约束，不能宣称整个生成器严格遵从真实动力学。
2. **已观测证据与未知区域分开。** 仅 `mask_camera` 有效的占据体素产生几何监督；有效空闲体素产生背景分类监督；未知区域与 ROI 外的预测不被当作空闲。所有 decoder 辅助层使用同一规则。观测掩码是数据集的有效域代理，不能等同于真实物理存在或完美可见性模型。
3. **用真实实例端点约束整段对应。** 原始 nuScenes annotation 的 instance token 提供跨帧身份；只选位于唯一语义兼容标注框内、相机掩码有效的真实占据点。框重叠歧义、未知端点均丢弃，不填框、不插值。每场景按固定 token 哈希最多选 32 条至少两端点的轨迹，每端点最多 16 个真实体素中心。预测查询与标注轨迹的 Hungarian 分配在全部观测端点上一次完成，不能逐帧更换对应。
4. **整段能量软边缘化。** 每个模式先汇总全部时域占据误差与端点匹配代价，再计算 `-tau*logsumexp(log_softmax(logits)-E/tau)`，`tau=0.25`，轨迹项权重 `0.2`。它是能量损失，不是已校准的完整概率似然；也未处理非独立删失的全部统计问题。推理按模型预测概率选择同一个完整模式，不读取 GT、不报告 oracle best-of-K 为主结果。

路径头输出层和概率头末层零初始化，各模式隐向量不同。两个模式起初与官方输出完全相同，更新后才允许分开；不通过给官方预测增加随机噪声制造初始差异。路径参数分别审计 `path_encoder`、`path_head`、`mixture_head`，允许零初始化导致的首批零梯度，但 smoke 最后两个窗口必须有真实梯度和更新。

## 与 A 相同和不同的条件

| 项目 | 约定 |
|---|---|
| 设备与 batch | GPU1 单张 H200；BS8；累积 1 |
| 数据预算 | 原 23,930 训练 anchor；seed 0；10 轮、29,920 iteration |
| 输入 | 相同历史相机、因果 radar cache、增强、未来自车位姿条件 |
| 初始化 | 完整官方 `sw-tc-small.pth`，669 原始 tensor 精确加载；新优化器、scaler、计数器 |
| 学习率 | AdamW 2e-5；backbone/sampling offset 2e-6；radar 和新 path 2e-4；原调度/裁剪 |
| 选模与主指标 | 每轮固定 256 验证；best/final 各 5,119；原四时域/17 类 mIoU |
| 新增内容 | 轻量路径/概率头、观测域损失、训练专用实例端点监督 |

**相同预算不意味着相同监督。** 本实验同时改变表示、损失、使用额外的标准 nuScenes 实例标注，属于一个组合原型。A 对照能回答整套方案在此预算下是否有效，不能单独归因到某组件。后续若有收益，仍需要等监督、等容量对照及逐组件训练消融。没有增加训练 anchor、未来图像输入或用验证标注训练。

原数据的 nominal 0/1/2/3 秒协议保留；真实时间戳只在端点 metadata 中记录，并不假称所有间隔恰好 0.5 秒。框由对应 LiDAR 帧的 ego pose 转到占据坐标，与 `fut2cur` 逐样本核对。缓存只保存关联元数据，不再复制 GT 或加入隐藏区伪标签；原始表、infos、builder、frame 内容均记录哈希。

## 提交与审计

源码使用独立 Git 提交和不可变远端快照，不修改 A/其他完成实验。`tools/launch_censored_path_campaign.py` 原子保留 `censored_path_campaign_20260926`，重复提交直接拒绝。

依次要求：精确版本 CPU 回归/预算/完整初始化检查 → GPU 契约 → 四个真实验证样本与**独立官方参考模型**的原始张量及最终输出等价 → 24 步 BS8 smoke → 所有模型/优化器 tensor 有限、新旧组件真实更新 → 重新从官方模型开始正式训练。smoke checkpoint 不用于正式初始化。

所有 GPU 阶段都持有既有 GPU1 文件锁，并等待空闲显存至少 132000 MiB 连续 60 秒；不结束其他账户任务。排队不算训练失败。训练保留动态 AMP，单次恢复的溢出不触发自动重启。实际失败先保留日志和收据，仅修复明确实现问题；不在结果出来后悄悄调整科学设计或预算。
