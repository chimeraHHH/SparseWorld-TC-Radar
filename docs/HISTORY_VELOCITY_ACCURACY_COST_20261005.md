# 两个速度模型的精度与成本进展（2026-10-05）

H2 速度模型最终完整验证的未来平均 mIoU 为 **24.9095385%**，H8 为 **25.8473652%**。两者差值为 **−0.9378266 个百分点**，按同一 150 个场景配对重采样 2000 次所得 95% 区间为 **[−1.1137544, −0.7696478]**。区间下界未超过预设的 −0.3 个百分点，因此此次 H2 未达到非劣标准。

这是同一科学快照、相同 5119 验证样本和十轮预算下的固定检查点比较。各时域场景顺序、样本索引和 token 对齐，逐场景真值计数完全一致。最终轮为主结果，best 为辅助；单种子、验证集复用和 H2 中断恢复后的 worker 随机分配变化均限制解释范围。

best 辅助比较使用 H8 epoch6 与 H2 epoch10，未来均值差 -0.9552683 个百分点，95% 区间 [-1.1425618, -0.7731243]，同样未达到非劣标准。该结果不替代预先规定的 final10 主比较。

H2 best10 在固定 256 子集上的独立正常评估为 24.0749103%，去掉雷达为 23.0279523%，速度置零为 23.7515013%，速度打乱为 23.7486049%。这表明本模型在该子集上对这些输入干预有响应，不能据此声称雷达速度造成了历史压缩收益。H8 几何臂仍暂缓，不计算缺失的四臂交互。只测了 H2/H8，不能宣称全局最少历史。

H2 原训练曾非正常退出；已从完整 epoch9 的模型、优化器和 FP16 状态恢复并重算未保存末轮。最终及最佳权重均为 epoch10、29920 runner 迭代、29911 次实际优化器更新，771 模型张量及优化器有限且 schema 一致。服务器完成权重 CPU 加载审计和 SHA 核对；权重未完整下载到本机重载。旧失败运行未保存末轮的实际优化消耗未知，成本单列。

GPU 收尾全部完成后，控制器因原干预 JSON 未输出顶层 token 而组装收据失败。独立 CPU 修复绑定原索引与训练 hook 的全量/子集 token，并复算原矩阵；不改写原输出，不重训或重复 GPU 评估。详见[收尾修复](H2_VELOCITY_FINALIZATION_20261005.md)。

**正式两臂成本尚未测量。** 已完成的单臂预备与失败缓存诊断永久排除正式配对；双方缓存配对路径仍不准入。训练数据正在迁至系统 NVMe，正式成本将使用双方相同的完整本地输入、原 BS1/30 预热/256 连续样本/16 场景/三次交替重放，并等待两卡无其他计算及原资源锁，不中断活训练。未测得的延迟、显存、GPU 能量或历史 I/O 收益不填估算值。

原 H2 仍保留八槽特征/投影开销，CPU 仍加载完整输入。新共享残差模型与分离几何、语义监督的独立残差对照属于后续主线，精度和效率收益尚未得到训练结果验证。
