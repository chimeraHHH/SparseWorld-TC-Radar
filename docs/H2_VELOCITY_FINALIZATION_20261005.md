# H2 速度模型：已完成 GPU 阶段的 CPU 收尾修复

末轮恢复训练、最终权重 CPU 审计、全量 5119 样本评估和四项 256 样本干预均已完成。恢复控制器随后在组装结果收据时退出：干预评估器保存 `indices`，但没有顶层 `tokens` 字段，收尾代码错误地访问该字段。该错误没有发生在训练或 GPU 评估阶段。

修复使用独立的 CPU 收尾入口 `tools/finalize_h2_velocity_saved.py`，不重复任何 GPU 阶段，也不改写原评估 JSON、矩阵、失败状态、领取或权重。原失败控制器、训练进程和干预进程均已观察退出，所属进程组为空。新收尾结果独立落盘，再原子、排他发布原本缺失的 H2 结果收据。

身份核对使用原干预索引、原训练 hook 的完整 5119 token 列表及固定 256 子集 token 列表，并核对各时域场景、索引和真值计数。原干预文件未直接输出 token，核对报告明确记录这种绑定方式，不将推导出的 token 冒充原文件字段。四时域、17 类、二元 IoU 和未来均值从原始混淆矩阵独立复算；正常干预与训练选模的比较沿用既有容差，聚合 0.001 个百分点、逐类 0.01 个百分点。

服务器已完整 CPU 加载审计最终及最佳权重，二者均为 epoch10、29920 runner 迭代、29911 次实际优化器更新，771 模型张量及优化器有限且 schema 一致。新收尾再次核对权重文件 SHA；这不等于权重已完整下载到本机重载。原未保存末轮的实际更新消耗仍未知，恢复时 worker 随机分配变化仍保留，不声称逐位等同不中断训练。

原全量 H2 未来 mIoU 为 **24.909538525592883%**，best 为 epoch10；固定子集正常干预为 24.074910252824377%，drop 为 23.027952313973014%，zero_velocity 为 23.751501342737743%，shuffle_velocity 为 23.748604861370538%。子集干预用于模型响应分析，不能替代全量主比较。与 H8 的全量配对统计、正式同本地输入成本和新模型结果另行报告。

回归覆盖无顶层 token 的原模式、索引顺序错误、子集 token 错误、已有 token 不符、实际 GPU 阶段失败、缺失成功阶段和禁止覆盖已有收据。修复不恢复用户取消的训练前 CPU/CUDA/anchor/smoke 检查，也不更改科学模型、预算或容差。
