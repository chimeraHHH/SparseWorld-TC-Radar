# 视觉历史 × 雷达速度：冻结的首轮研究与训练协议

2026-09-27。用户已授权继续研究并提交 H200。本轮检验假设，不宣称新架构已有收益。停止的 B balanced 和 censored-path 及其评估队列保持取消；不重训 A、camera、belief、transport-reliable。

## 问题与四组设计

检验：当前雷达的处理后速度信息是否在短视觉历史条件下具有更大的未来预测价值，以及能否补回缩短视觉历史的性能损失。保持相机—雷达未来 3D 语义占据任务。

| 臂 | 实际图像输入 | 雷达输入 |
|---|---|---|
| h1-geometry | 当前时刻六路图像 | 每传感器最新因果一扫，速度三通道置零 |
| h1-velocity | 当前时刻六路图像 | 同一批点，保留 SDK 补偿速度及其径向投影 |
| h8-geometry | 原八时刻、六视角 | 与 h1-geometry 相同雷达协议 |
| h8-velocity | 原八时刻、六视角 | 与 h1-velocity 相同雷达协议 |

四臂使用同一 A transport 架构、相同损失、官方完整模型初始化及新优化器。每臂单 H200，BS8、累积1、seed0、10轮、29920 iterations；同23930训练和5119验证 anchors。差分学习率与 A 相同。没有新增实例监督、路径损失、可靠度门控或多模态分支。四臂总计119680正式 iterations；不复用先前多sweep A作为四组中某一臂。

## 输入与初始化

H1正式pipeline不加载任何历史图像，backbone只编码当前6图；将其特征、时间戳及相机投影复制到8个槽位，保留全部669官方参数张量的形状和值，雷达102个新张量按相同seed初始化、六处残差输出置零。H8读取原48图。H1复制的是当前观测，不是合成历史；参数预算相同但时序采样计算仍保留。不是原八帧预测的输出等价。

每臂用四个真实anchor，对独立camera参考执行初始化输出核对。H1参考独立编码6图并手工拼接特征/元数据；H8参考使用真实48图。记录实际backbone图数，13个原始输出逐一核查，预设atol=1e-4、rtol=1e-5并披露实际误差；最终体素输出要求一致。输入变换不增加训练参数。

单扫缓存从原始sample_data链为五个传感器分别选择timestamp≤LiDAR anchor的最新一扫，保留异步age≤0.5秒；其next timestamp证明没有跳过更新的因果扫。几何与速度两臂读同一缓存，几何视图只在完整性校验后置零vx/vy/derived radial。速度不参与点成员筛选；四臂共同关闭原A的35m/s速度阈值过滤，以避免零速度重新纳入被过滤点。SDK共同点质量过滤仍存在，故geometry应理解为“没有额外速度通道”，不能宣称完全不含传感器预处理的运动先验。

这里使用nuScenes处理后的vx_comp/vy_comp，并非独立保留的原始scalar Doppler；不将当前结果等同原始雷达信号级可观测性结论。单次雷达扫描本身也占用有限采集时间。

## 准入与调度

独立immutable源码快照、campaign history_doppler_campaign_20260927。精确版本CPU回归、相同输入协议/优化器审计、全缓存验证与128在线复核、CUDA契约、四样本输出核对、24步BS8 smoke。审计模型和优化器有限、24次真实优化更新、新雷达与预训练组件均实际更新后，才以新进程从官方权重正式训练，禁止使用smoke权重。

可用GPU worker按顺序原子领取 h1-velocity、h1-geometry、h8-velocity、h8-geometry；卡被占用时不领取，另一可用卡可以继续领取后续臂。每卡既有forecast锁；每个GPU阶段要求无其他compute进程且空闲≥132000MiB连续60秒。GPU0现有其他账户任务不结束、不干预。只启动一次、失败留证据，不自动重启或改科学配置。

## 主比较与判据（结果前预先确定）

固定第10轮为主比较，固定256子集选出的最佳训练轮为辅助。best/final均全量5119，并保存各时域、类别、场景混淆矩阵；最佳模型执行256正常/去雷达，含速度两臂另做速度置零/打乱。后两种是分布外依赖干预，不能替代geometry训练对照。

D(H)=future_mIoU(H,velocity)-future_mIoU(H,geometry)。主交互量 I=D(1)-D(8)。四组采用同一2000次场景配对bootstrap，先聚合混淆矩阵再计算非线性mIoU；I区间下界>0支持短历史下更大的速度价值。另检验h1-velocity相对h8-velocity的差异，其95%区间下界>-0.3pp作为本轮预设非劣工程门槛；不能单凭I>0声称实现替代。

报告当前帧及各未来时域/类别、真实离线耗时/峰值显存/训练成本。由于online原模型已有缓存，不从离线图数推断持续运行8倍加速。若主比较支持假设，再使用同一模型的当前预测静态输运和已知/未知、变化区域分层诊断，以区分感知收益和预测收益；这些额外诊断尚不是自动队列完成项，不得声称已做。纯相机H1/H8与其他种子是后续扩展，不将原camera多sweep或不同history结果冒充匹配对照。

## 解释边界与下一步

此轮是四组机制实验，不是已完成的“最小预测记忆”新模型贡献。若短历史下速度无增益、几何解释全部收益、仅当前感知改善或无稳定成本优势，就降低或否定该假设，不能为保结论临时换主指标。若现象成立，再以信息分工设计观测条件化视觉记忆，与普通短历史融合、选帧和蒸馏比较。

固定256在5119中且已多次用于研究选择；单种子，未完成独立盲测。场景bootstrap只刻画固定权重/这些场景的抽样不确定性，不能替代跨seed。已有停止实验不能记为完成相同预算的负结果。
