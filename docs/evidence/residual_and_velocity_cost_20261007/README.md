# 原数值证据与正式成本

52 个 NPZ 保持原字节：独立残差 28 个、共享残差 24 个。四份训练验证 JSON 保持原字节，提供完整与最佳子集的 indices/tokens。共享 best10 与 final10 相同，没有重复全量评估。

半秒 frame offset 0/2/4/6 对应文件 0/1/2/3 秒。四干预原 JSON 未输出 tokens，按其 indices 与最佳子集及全量 tokens 绑定。逐时域逐场景混淆矩阵及真值类别计数支持配对；场景自举统计已完成，未重新执行实验。

六份正式速度成本 JSON 保留所有原数值行、protocol、tokens、检查点 SHA 和时长，仅移除两种私有路径字段。MANIFEST.json 同时记录公开字节 SHA 与原 JSON SHA；原私有文件保留。缓存路径和预备、失败块不进入正式成本。

时间分位数使用原每样本行，三次重放各 256 样本；pooled 分位数合并三次重放，共 768 行。I/O 读取收据是去重采样，logical_file_bytes 与图像 tensor 字节不是物理磁盘或 DMA 传输计数。OS 缓存未控制，GPU 累计能量若不支持则保留 null，不估算整机能耗。

完整权重加载和有限性来自服务器原 CPU 审计，本机只独立复算矩阵与成本行，未完整下载或重载权重。
